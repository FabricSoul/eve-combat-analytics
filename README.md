# EVE Combat Analytics

Fleet-fight review for EVE Online: paste a br.evetools.org battle report, everyone in the fight drops in their Gamelog,
and the page shows — live, for everyone — who did what to whom and when.

Rewrite in progress on branch `FabricSoul/revive`. The previous SvelteKit version is in the git history.
